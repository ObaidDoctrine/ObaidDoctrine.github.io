# OBAID DOCTRINE — Permanent Brand System

Version: 1.0
Status: Approved implementation baseline
Parent brand: OBAID DOCTRINE
Tagline: BETTER MIND • BETTER CHARACTER • BETTER LIFE

## Core palette
- Signature Orange: #E8752A — primary brand accent, links, active states and key calls to action.
- Warm Cream: #FFF7ED — primary warm page background and brand canvas.
- Deep Brown: #49382D — headings and strong text.
- Soft Orange: #F4A261 — secondary highlight, used sparingly.
- Warm Beige: #E8D8C5 — borders and dividers.
- Pale Orange: #FCE8D8 — subtle surfaces and hover backgrounds.

## Usage
- Keep content surfaces predominantly cream or white; do not make every page fully orange.
- Use orange for recognizable brand accents, not long blocks of body text.
- Use deep brown for headings and high-emphasis text.
- Keep contrast readable in English and Urdu.
- Use the same palette on the website, social profile assets, covers, posters and video end cards.
- Topic imagery may vary; the brand palette must remain recognizable.
- Do not add black-heavy themes or unrelated per-platform palettes.
